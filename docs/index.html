MCP Overlord

Give your AI hands. Supervise accordingly.

What it is

MCP Overlord is a Windows desktop app that hosts an MCP server. A client such as Cursor can see a window named in a config file, take a screenshot of it, and send mouse and keyboard input. The usual target is a game. The model decides what to do. This program carries it out, then reports what happened.

It speaks MCP over HTTP on loopback, at http://127.0.0.1:5000/mcp with the default config. Install the MSI, load a .overlord file, start the server from the window, and point the client at that URL. 64-bit Windows 10 or 11. MIT license.

What it does

  • Takes a screenshot of a configured window and hands the image back to the model. Later clicks use pixels of that image, with the origin at the top left of the window.
  • Moves the mouse, clicks, scrolls, presses keys, and types text into that window. The window is focused first.
  • Finds the window from its title, process name, or executable, and can launch the executable listed in the config.
  • Shows a small dark window with start and stop, a live log, and counters, so you can watch the session.

Tools: list_applications, get_application_description, launch_application, find_window, focus_window, take_screenshot, mouse_move, mouse_click, mouse_down, mouse_up, mouse_scroll, key_press, key_down, key_up, type_text, is_locked, and lock.

Connect a client

Cursor on the same machine, with no API key:

{
  "mcpServers": {
    "game-control": {
      "url": "http://127.0.0.1:5000/mcp"
    }
  }
}

The default listener is 127.0.0.1. Other machines cannot reach it. Treat the endpoint as a keyboard that happens to speak HTTP.

Install

The MSI for 64-bit Windows 10 or 11 is attached to release_1. The package carries the runtime, so the machine does not need the .NET SDK. The installer adds a Start menu shortcut named MCP Overlord and registers the .overlord extension.

Building from source is documented in the README. The behavior contract, including every argument, is the design document.
